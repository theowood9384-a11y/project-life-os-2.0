## ✨ 这是什么

**项目人生 OS** 是一个完全运行在你自己电脑上的 Obsidian 仓库（vault）。

- 🔒 **本地优先**：所有内容都是普通的 Markdown 文件，不需要注册账号；哪天不用 Obsidian 了，用记事本也能打开。
- 🌏 **对话主界面**：打开就是一幅会动的竖线网屏画（此刻的地球、扫描框里的人像、今年做过的事堆成的山脊），旁边就能直接和 AI 对话。
- 🏠 **一个主页看全局**：今日头号要事、今天待办、逾期、本周、项目进度、习惯与心情节奏，一屏看完。
- ⚡ **一句话记录**：在主页输入「明天 14:00 写周报 #工作 !!」，日期、时间、标签、优先级自动识别。
- 🤖 **AI 加持**：电脑上用 Claudian 直接问「今天该先做什么」；接入 OpenClaw 后，在微信 / 飞书里说一句话就能记进仓库。
- 🧩 **开箱即用**：4 个专属插件 + 7 个精选社区插件已预装、预配置，打开即用。

## 🚀 3 分钟上手

1. **安装 Obsidian**：到 [obsidian.md](https://obsidian.md) 下载最新版（免费）。
2. **获取仓库**：点本页右上角 `Code → Download ZIP` 下载并解压（或 `git clone`），把里面的 `项目人生OS` 文件夹放到「文稿 / Documents」等常用位置。
   - 文件夹名可以改，里面的结构不要改。
3. **打开仓库**：Obsidian 中选择「打开本地仓库」（Open folder as vault），选中 `项目人生OS` 文件夹。
4. **信任插件**：弹出「是否信任此仓库的作者？」时，点 **【信任作者并启用插件】**。
   > ⚠️ 如果点成了「以受限模式浏览」：设置 → 第三方插件 → 关闭「受限模式」→ 把列表里的插件逐个打开。
5. 中间会自动打开 **项目人生主页**，再打开左侧的 `从这里开始.md`，跟着 5 分钟上手走一遍。

更多说明见 [使用前必读.txt](./使用前必读.txt)。

## ✍️ 一句话加任务

在主页「今天」卡片的输入框里写一句话、回车即可：

| 输入 | 效果 |
|---|---|
| `给家里打电话` | 今天要做 |
| `明天 14:00-15:00 写周报 #工作 !!` | 明天 14 点，标签「工作」，高优先级 |
| `周五前交方案` | 截止周五 |
| `下周三 去医院复查 @健康计划` | 放进「健康计划」项目 |

`!` `!!` `!!!` 分别代表中、高、最高优先级；`@项目名` 只写前几个字也能识别。

### 数据格式约定

```markdown
- [ ] 写周报 #工作 ⏫ 📅 2026-01-20          ← 任务（⏳ 打算哪天做，📅 最晚完成日）
- 2026-01-15 09:30 想法内容 #标签             ← 闪念
- 08:10 😊 开心 [情绪:: happy] [强度:: 7] 睡得很好  ← 心情
```

完整规则见 [`00-后台/数据格式规范.md`](./项目人生OS/00-后台/数据格式规范.md)。按这个格式写，主页、插件和 AI 都能读懂。

## ❓ 常见问题

<details>
<summary><b>手机上能用吗？</b></summary>

可以在手机版 Obsidian 打开同一个仓库（用 Obsidian Sync、iCloud 或 Git 同步）。其中 Claudian 只能在电脑上用。
</details>

<details>
<summary><b>我的数据存在哪里？会联网吗？</b></summary>

全部是你电脑上的普通 Markdown 文件。会联网的只有：书签收藏盒抓取已收藏网页的标题和封面、可选的链接有效性检测；情绪追踪器的语音对话（仅在填了 ElevenLabs API Key 并点麦克风时）；以及你自己接入的 OpenClaw / Claudian。
</details>

<details>
<summary><b>示例内容怎么删？</b></summary>

点主页「欢迎」卡片里的「清除示例内容」即可一键清除（示例笔记移到 `.trash`，你自己写的内容不受影响）。也可以在 Obsidian 里搜索 `tag:#示例` 手动删除。
</details>
