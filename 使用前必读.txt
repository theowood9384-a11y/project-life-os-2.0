项目人生 OS · 使用前必读
========================

感谢使用项目人生 OS。下面 4 步，3 分钟就能用起来。


一、安装 Obsidian
-----------------
到 https://obsidian.md 下载并安装最新版 Obsidian（免费）。


二、放好仓库文件夹
-----------------
1. 解压后，把「项目人生OS」这个文件夹放到你常用的位置，
   例如「文稿」或「Documents」。
   · 不要直接在压缩包里打开，也不要放在「下载」里以免误删。
2. 文件夹名可以改，里面的结构不要改。


三、用 Obsidian 打开
--------------------
1. 打开 Obsidian，选择「打开本地仓库」（Open folder as vault），
   选中刚才的「项目人生OS」文件夹。
2. 会弹出「是否信任此仓库的作者？」——
   请点【信任作者并启用插件】（Trust author and enable plugins）。

   ⚠ 如果点成了「以受限模式浏览」，主页和插件都不会出现。补救方法：
     设置 → 第三方插件 → 关闭「受限模式」→ 把列表里的插件逐个打开。

3. 成功后，中间会自动打开「项目人生主页」。
   左侧文件列表里找到「从这里开始」，按里面的 5 分钟上手走一遍。


四、可选：在微信 / 飞书里使用
----------------------------
需要一台常开的电脑并安装 OpenClaw。
步骤见仓库内：00-后台/OpenClaw/安装说明.md


常见问题
--------
· 手机上能用吗？
  可以在手机版 Obsidian 打开同一个仓库（用 Obsidian Sync、iCloud 等同步）。
  其中 Claudian 只能在电脑上用。

· 我的数据存在哪里？
  全部是你电脑上的普通 Markdown 文件，不需要注册账号。
  会联网的只有：书签收藏盒抓取已收藏网页的标题和封面、可选的链接有效性检测；
  情绪追踪器的语音对话（只有你填了 ElevenLabs API Key 并点麦克风时）；
  以及你自己接入的 OpenClaw / Claudian。

· 情绪追踪器的语音对话怎么用？
  这是可选功能。到 elevenlabs.io 注册并创建 API Key（付费需外币卡，网络要能访问 ElevenLabs），
  在 设置 → 情绪追踪器 → 语音对话 里填好，点「测试」，之后首页点麦克风就能聊。
  声音和对话内容会发给 ElevenLabs 和所选的大模型；插件不保存对话全文，
  只在你确认后把一条情绪记录写进当天日记。它是陪你聊聊的倾听者，不是心理咨询。

· 示例内容怎么删？
  在 Obsidian 里搜索 tag:#示例，删除找到的内容即可。
