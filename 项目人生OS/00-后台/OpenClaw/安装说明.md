# 在微信 / 飞书里使用项目人生 OS

装好以后，你可以直接在微信或飞书里对 OpenClaw 说：

> 闪念：把四象限做成主页的一个模块
> 周五前把方案发给老板，重要
> 跑步打卡
> 心情 7 分，今天睡得很好
> 收藏 https://sspai.com
> 今天有什么事？

它会按《数据格式规范》写进这个 vault，Obsidian 主页会自动刷新显示。

---

## 一、准备

- 一台**常开的电脑**（或服务器），上面有这个 vault，并安装了 OpenClaw。
- Node.js 18 或更高版本（安装 OpenClaw 时通常已经有了）。
- 想在手机上的 Obsidian 也看到内容，需要另外设置同步（Obsidian Sync、iCloud 或 Git 均可）。

## 二、让 OpenClaw 加载技能

把下面命令里的路径换成你的 vault 实际位置：

```bash
openclaw config set skills.load.extraDirs '["/Users/你的用户名/Documents/项目人生OS/00-后台/OpenClaw"]' --strict-json
```

```bash
openclaw gateway restart
```

```bash
openclaw skills list
```

列表里出现 `project-life-os` 就成功了。

> 如果你之前已经配置过 `skills.load.extraDirs`，请把这个路径**追加**进原来的数组，不要整个替换。
>
> 技能会自动找到它所在的 vault。如果你把技能文件夹复制到了别处，需要告诉它 vault 在哪：
> `openclaw config set skills.entries.project-life-os.env.PROJECT_LIFE_VAULT "/vault/的/路径"`

## 三、接入聊天软件

### 飞书（推荐）

按 OpenClaw 文档《Feishu》在飞书开放平台创建企业自建应用并接入。

### 微信

OpenClaw 通过腾讯提供的 `openclaw-weixin` 插件接入微信，在运行 OpenClaw 的电脑上执行：

```bash
openclaw plugins install "@tencent-weixin/openclaw-weixin"
```

```bash
openclaw channels login --channel openclaw-weixin
```

用手机微信扫码确认即可。

## 四、安全设置（务必做）

这个技能能改写你的 vault，所以**只让你自己能指挥它**：

- 私聊策略用 `pairing`（陌生人会收到配对码，需要你在电脑上批准）或 `allowlist`（只允许名单里的账号）。**不要**设成对所有人开放。
- 有人申请配对时，先确认是你本人再批准：`openclaw pairing list <通道>` → `openclaw pairing approve <通道> <配对码>`。
- 技能只会写入规范允许的位置（`01-捕获`、`02-项目`、`03-行动/日记`、`04-复盘/周复盘`），不会删除文件，也不会改 `.obsidian` 和模板。
- 如果你开启了 OpenClaw 的命令审批（exec approvals），需要允许它用 `node` 运行 `00-后台/OpenClaw/project-life-os/scripts/pl.mjs`。

## 五、试一试

在聊天里发「今天有什么事」，应该会收到今日任务、习惯和心情的汇总。

也可以在电脑终端里直接测试（不经过聊天）：

```bash
node "/Users/你的用户名/Documents/项目人生OS/00-后台/OpenClaw/project-life-os/scripts/pl.mjs" today
```

## 常见问题

| 现象 | 处理 |
|---|---|
| `openclaw skills list` 里没有 project-life-os | 检查 `extraDirs` 路径是否指向 `00-后台/OpenClaw` 这一层；改完要 `openclaw gateway restart` |
| 回复「找不到项目人生 vault」 | 技能文件夹被移出了 vault，按第二步设置 `PROJECT_LIFE_VAULT` |
| 写进去了但 Obsidian 主页没变 | 确认电脑上的 Obsidian 打开的是同一个 vault；手机端需等同步完成 |
| 「看不懂日期」 | 换个说法：明天、周五、下周三、11月20日、2026-11-20 |
