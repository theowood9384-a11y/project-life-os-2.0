# 项目人生 · 数据格式规范 v1.0

这份规范是 **4 个插件、OpenClaw 技能包、模板** 三方共同遵守的约定。
任何一方读写数据，都以本文为准；本文与代码冲突时，改代码。

---

## 0. 总原则

1. **用户数据只存在 Markdown 里。** 插件的 `data.json` 只能放「设置」和「可重建的缓存」（如网页标题、封面图缓存、卡片位置），不能放任何只有那里才有的用户内容。
2. **一类数据，一个位置，一种写法。** 同一件事不允许两种格式。
3. **只追加，不重写。** 新记录追加到指定位置；修改只改那一行；不认识的内容原样保留。
4. **原子写入。** 插件内一律用 `app.vault.process()`；外部程序（OpenClaw）写文件时整文件一次写完，不分段写。
5. **插件必须感知外部改动。** 监听 `metadataCache.on("changed")` / `vault.on("modify"|"create"|"delete"|"rename")` 刷新，不靠轮询。
6. **删除 = 移入 `.trash/`**（Obsidian 本地回收站），不做物理删除。
7. **文件编码**：UTF-8、无 BOM、LF 换行、文件末尾保留一个换行。

### 通用写法

| 项 | 写法 | 例 |
|---|---|---|
| 日期 | `YYYY-MM-DD` | `2026-11-16` |
| 日期时间 | `YYYY-MM-DD HH:mm`（24 小时制） | `2026-11-16 09:05` |
| 时间 | `HH:mm`（两位小时） | `09:05` |
| 标签 | `#标签`，可用层级 `#工作/客户` ，不含空格 | `#读书` |
| 双链 | `[[笔记名]]` | `[[项目人生OS]]` |

### Frontmatter 键名

- Obsidian 保留键用英文：`tags`、`aliases`、`cssclasses`。
- 其余一律用中文键，并在 `.obsidian/types.json` 声明类型。
- 每篇由系统生成的笔记都必须有 `类型`。

| 键 | 类型 | 取值 |
|---|---|---|
| `类型` | 文本 | 见各节，取值固定 |
| `创建时间` | 日期 | `YYYY-MM-DD` |
| `日期` | 日期 | 日记、复盘专用 |
| `领域` | 文本 | `财富` / `健康` / `关系` / `成长` / `其他` |
| `状态` | 文本 | 项目专用，见 §5 |
| `开始时间` / `截止时间` | 日期 | 项目专用 |
| `目标` | 文本 | 项目专用 |
| `来源` | 文本 | 文献笔记专用，URL 或书名 |
| `tags` | 列表 | `[读书, 方法]`（列表内不写 `#`） |

## 2. 任务

### 2.1 位置

| 场景 | 写到哪里 |
|---|---|
| 不属于任何项目的任务（收件箱） | `01-捕获/我的任务.md` 末尾 |
| 属于某个项目的任务 | 该项目笔记 `## ✅ 任务` 标题下 |
| 日记里临时写的任务 | 当天日记 `## 📢 今日任务` 标题下 |

### 2.2 单行语法（与 Tasks 插件兼容）

```
- [状态] [时间 ]内容[ #标签…][ 优先级][ 🔁 重复][ 🛫 开始][ ⏳ 计划][ 📅 截止][ ✅ 完成]
```

字段 **按上面的顺序** 出现，方括号内的部分可省略：

| 字段 | 写法 | 说明 |
|---|---|---|
| 状态 | `[ ]` 未完成 · `[x]` 完成 · `[-]` 取消 · `[/]` 进行中 | 读取时 `X` 等同 `x` |
| 时间 | `HH:mm` 或 `HH:mm-HH:mm` | 紧跟在状态后面 |
| 内容 | 纯文字，可含 `[[双链]]` | 不能含 `📅⏳🛫✅🔁` 等字段符号 |
| 标签 | 放在内容之后 | |
| 优先级 | `🔺` 最高 · `⏫` 高 · `🔼` 中 · `🔽` 低 | 决定任务排序和主页提醒的轻重 |
| 🔁 重复 | Tasks 语法，如 `🔁 every week` | |
| 🛫 开始 | 日期 | 从哪天起才需要关注 |
| ⏳ 计划 | 日期 | **打算哪天做**（"今天要做的事"用它） |
| 📅 截止 | 日期 | **最晚哪天必须完成**（"周五前交"用它） |
| ✅ 完成 | 日期 | 勾选完成时追加 |

**例：**

```markdown
- [ ] 写周报 #工作 ⏫ 📅 2026-11-20
- [ ] 14:00-15:00 和导师开会 ⏳ 2026-11-17
- [x] 交水电费 #生活 ⏳ 2026-11-15 ✅ 2026-11-15
```

### 2.3 规则

- 一行一个任务；不加空行、分隔线或时间戳块（废弃 `---\n☑️ 时间` 写法）。
- 子任务用 Tab 缩进一层，最多一层。
- 模板里不放空任务 `- [ ]`，否则每篇新笔记都会在任务查询里多出一条空任务。
- 完成任务：把 `[ ]` 改成 `[x]`，并在行尾追加 `✅ YYYY-MM-DD`。
- 任务必须是顶格（或 Tab 缩进）的 `- [ ]`，**不能写在 callout（`> - [ ]`）里**，否则主页统计不到。

- 多行内容：第二行起用 Tab 缩进。
- 已整理成笔记的闪念：在行尾追加 ` → [[笔记名]]`，不删除原行。

## 4. 习惯 `01-捕获/习惯追踪.md`

```markdown
---
类型: 习惯追踪
---
# 习惯追踪

## 🏃 跑步

- [x] 2026-11-15
- [x] 2026-11-16

## 🧘 冥想

- [x] 2026-11-16
```

- 一个习惯 = 一个 `##` 标题：`## 表情 习惯名`（表情可省略）。习惯名在全文件唯一。
- 打卡 = 在该标题下追加 `- [x] YYYY-MM-DD`，按日期升序，同一天只写一次。
- 取消打卡 = 删除那一行。
- 不使用 `###` 及更深层级标题。

## 5. 项目 `02-项目/1.进行项目/<项目名>.md`

### 5.1 Frontmatter

```yaml
---
类型: 项目
目标: 年底前完成产品 1.0 上线
领域: 成长
状态: 进行中
开始时间: 2026-11-16
截止时间: 2026-12-31
tags: [项目]
---
```

| `状态` 取值 | 含义 | 所在文件夹 |
|---|---|---|
| `进行中` | 正在推进 | `1.进行项目` |
| `暂停` | 暂时搁置 | `1.进行项目` |
| `完成` | 已达成目标 | `2.归档项目` |
| `放弃` | 不再推进 | `2.归档项目` |

### 5.2 正文固定标题

```markdown
## 🎯 项目描述
## ✅ 任务
## ❓ 问题
## 📚 资源
## 💡 灵感
## 🏆 成就
```

- 标题文字固定（插件和 AI 靠它定位插入点），标题下内容格式自由，任务除外（见 §2）。
- 项目文件名就是项目名，不加日期前缀。

## 6. 日记 `03-行动/日记/YYYY-MM-DD.md`

```markdown
---
类型: 日记
日期: 2026-11-16
tags: [日记]
---
# 2026-11-16 星期一

## 📢 今日任务
（Tasks 查询块 + 当天临时任务）

## 📝 记录
- 09:30 开完周会，确定了下周重点

## 😊 今日情绪
- 08:10 😊 开心 [情绪:: happy] [强度:: 7] 睡得很好
- 15:40 😰 焦虑 [情绪:: anxious] 方案还没定

## 🛑 复盘
- 做得好：
- 待改进：
- 明天：
```

- 日记不存在时，**插件和 AI 都必须先用 `00-后台/模板/日记模板.md` 创建**，再写入。不允许各自生成不同的默认结构。
- `## 📝 记录`：一条一行 `- HH:mm 内容`，按时间追加。

### 6.1 情绪记录（写在当天日记 `## 😊 今日情绪` 下）

```
- HH:mm 表情 中文名 [情绪:: 键] [强度:: 1-10] 内容
```

- `[强度:: …]` 可省略；内容可省略。
- 使用 Dataview 行内字段，AI、Dataview、插件都能直接读取。
- 不再写 HTML `<div>` 卡片；卡片样式由插件视图或 CSS 片段负责渲染。

| 键 | 中文名 | 表情 |
|---|---|---|
| `happy` | 开心 | 😊 |
| `sad` | 悲伤 | 😢 |
| `angry` | 愤怒 | 😠 |
| `anxious` | 焦虑 | 😰 |
| `calm` | 平静 | 😌 |
| `neutral` | 平常 | 😐 |
| `excited` | 兴奋 | 🤩 |
| `tired` | 疲惫 | 😴 |
| `grateful` | 感恩 | 🙏 |
| `stressed` | 压力 | 😫 |

自定义情绪：键用英文小写，在插件设置中登记后才可使用。

## 7. 收藏 `01-捕获/收藏夹.md`

```markdown
---
类型: 收藏夹
---
## 📥 待整理

- [少数派](https://sspai.com) #阅读
	高质量数字生活媒体

## 常用工具

### 设计

- [Figma](https://www.figma.com) #设计
```

- 分类 = `##`，子分类 = `###`（最多两级）。
- 一条书签一行：`- [标题](URL) #标签`；描述写在下一行，Tab 缩进。
- 来自聊天、未分类的新链接一律追加到 `## 📥 待整理`。
- 同一 URL 全文件只出现一次。
- 自定义标题、描述必须写回这个文件；`data.json` 里只保留抓取到的标题、简介、封面图缓存。

## 9.5 模板占位符

所有模板只用下面 4 个占位符（Obsidian 核心「模板」「日记」插件的语法），**不用 Templater 语法**。
这样核心插件、情绪追踪器、项目人生系统、OpenClaw 新建笔记时用同一套替换规则：

| 占位符 | 替换为 | 例 |
|---|---|---|
| `{{title}}` | 新文件名（不含 `.md`） | `2026-11-16`、`产品上线` |
| `{{date}}` | 当天日期 `YYYY-MM-DD`（日记为该日记的日期） | `2026-11-16` |
| `{{date:格式}}` | 按 moment 格式输出该日期 | `{{date:YYYY年M月D日 dddd}}` |
| `{{time}}` | 当前时间 `HH:mm` | `09:05` |

模板中的 `{{query.file.filenameWithoutExtension}}` 属于 Tasks 查询语法，**原样保留，不替换**。

## 10. 外部程序（OpenClaw）写入边界

外部程序一律通过 `00-后台/OpenClaw/project-life-os/scripts/pl.mjs` 写入，该脚本是本规范的参考实现；接入方法见 `00-后台/OpenClaw/安装说明.md`。

| 允许 | 禁止 |
|---|---|
| 按本规范追加：任务、闪念、打卡、情绪、记录、收藏 | 修改 `.obsidian/` 下任何文件 |
| 用模板新建：日记、项目、笔记、周复盘 | 修改 `00-后台/`（模板、规范） |
| 勾选任务、改项目 `状态`、把项目移入归档 | 物理删除文件 |
| 读取全库 | 改写已有记录的原文（勾选、追加 `→ [[…]]` 除外） |
