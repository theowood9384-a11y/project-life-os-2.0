# 👋 从这里开始

欢迎使用**项目人生 OS**。它是一个完全在你电脑上的 Obsidian 仓库：所有内容都是普通的 Markdown 文件，不联网、不登录，哪天不用 Obsidian 了，用记事本也能打开。

> [!tip] 5 分钟上手
> 1. 每次打开 Obsidian，中间先是 **对话主界面**：一幅字符画（地球 / 痕迹 / 一年）和一个输入框，直接问 AI 或说「闪念：…」就能记下。点右下角「进入主页」看完整的 **项目人生主页**，主页左上角「← 回到对话」再切回来。主页固定为标签页，点开其他笔记不会把它替换掉。
> 2. 点主页右下角的悬浮球，输入「闪念：……」或「跑步打卡」，回车就记下了。电脑上启用了 Claudian 的话，还可以直接问它「今天该先做什么」。悬浮球可以拖到左右两侧任意高度。
> 3. 在主页「节奏」里点一下今天的方格，完成一次打卡。点习惯名可以换颜色。
> 4. 点左侧日历里的今天，写下第一篇日记。
> 5. 想在手机上用微信/飞书记录，看 [[安装说明]]。

## 一天怎么用

| 时间 | 做什么 | 在哪里 |
|---|---|---|
| 早上 | 看今日头号要事和今天的清单 | 中间常驻的主页 |
| 随时 | 想到事情就记：任务、闪念、打卡 | 电脑上：主页「今天」输入框或右下角悬浮球；手机上：微信 / 飞书 |
| 随时 | 心情有波动时记一笔 | 左侧栏爱心图标（情绪追踪器） |
| 晚上 | 写几句日记，勾掉完成的任务 | `03-行动/日记/今天.md` |
| 每周 | 回顾一周，整理闪念和收藏 | `04-复盘/周复盘` |

## 文件夹是做什么的

| 文件夹 | 放什么 |
|---|---|
| `00-后台` | 模板、规范、附件、AI 技能——平时不用管 |
| `01-捕获` | 四个固定入口：我的任务、我的闪念、习惯追踪、收藏夹 |
| `02-项目` | 每个项目一篇笔记；做完或放弃的移到「归档项目」 |
| `03-行动/日记` | 每天一篇日记，文件名就是日期 |
| `04-复盘/周复盘` | 每周一篇复盘，文件名如 `2026-W03` |
| `05-笔记` | 沉淀下来的知识：永久、文献、剪藏、可视笔记 |

## 四个专属插件

| 插件 | 作用 | 打开方式 |
|---|---|---|
| **项目人生系统** | 打开先是对话主界面：字符场景（地球、痕迹、一年三选一，设置里可换彩色 / 黑白）加 AI 对话；点「进入主页」是原来的主页：今日头号要事和四个数字（今天待办、逾期、今天完成、待整理），下面是今天、节奏（心情与习惯）、本周、项目、待整理；右上角搜索；右下角悬浮球一句话记录或问 AI | 启动时自动打开并固定在中间 · 左侧栏图标 |
| **捕获便利贴** | 侧栏里的一面便利贴墙：闪念和小事随手贴，按颜色、标签整理，可以置顶、自由摆放；有手帐、静物、笺、孔版、简洁五种风格，页面最下面的「风格」随时切换，做完一件会被撕下、盖章或揉掉；主页「闪念」卡片的「到便利贴墙整理」也会打开它 | 左侧栏便利贴图标 |
| **情绪追踪器** | 记录此刻的心情和强度，写进当天日记；有光球、手帐、电台、色谱四种风格（「主题」里切换）；填好 ElevenLabs API Key 后，点麦克风能和 AI 语音聊心情，聊完它整理成一条记录，你确认后才写进日记 | 左侧栏爱心图标 |
| **书签收藏盒** | 用卡片浏览「收藏夹」里的链接 | 左侧栏书本图标 |

另外还装了：Tasks（任务）、Dataview（查询）、Calendar（日历）、Day Planner（时间轴）、QuickAdd（快速新建，`Ctrl/Cmd + P` 搜「新建笔记」）、Excalidraw（手绘图）、Claudian（电脑端 AI 对话，需另装 Claude Code）。

## 在主页直接加任务

主页「今天」卡片最上面有一个输入框（点右上角「+ 任务」也会跳到这里），写一句话、回车就保存：

- `给家里打电话` → 今天要做
- `明天 14:00-15:00 写周报 #工作 !!` → 明天 14 点，标签「工作」，高优先级
- `周五前交方案` → 截止周五
- `下周三 去医院复查 @健康计划` → 放进「健康计划」项目

`!` `!!` `!!!` 分别是中、高、最高优先级；`@项目名` 写前几个字就行。输入时下方会显示「将保存为：……」，点右边的「更多选项」可以打开完整表单。

便利贴墙「+ 新建」选「任务」时也认这套写法，只是不认 `@项目`（便利贴不分项目），没写日期就不排日期。

每条任务左边有一个圆圈，点一下就完成；鼠标移到这一行，右边会出现「推到明天」和「⋯」，点「⋯」或右键，可以改日期、改优先级、取消。每次操作后底部会出现「撤销」，几秒内都能反悔。

「我的任务」里没写日期的事不进今天的清单，会单独列在「没排日期」下面，点「排到今天」就加进来了。

找东西用右上角的搜索框（`Cmd/Ctrl + K`），任务、项目、笔记、闪念、收藏都能搜到。

## 几个写法约定

- **任务**：`- [ ] 写周报 #工作 ⏫ 📅 2026-01-20`
	- ⏳ 是"打算哪天做"，📅 是"最晚哪天完成"
	- 🔺⏫🔼🔽 是优先级（最高 → 低），日记里的今日任务按它排序
- **闪念**：`- 2026-01-15 09:30 想法内容 #标签`
- **心情**：`- 08:10 😊 开心 [情绪:: happy] [强度:: 7] 睡得很好`

完整规则见 [[数据格式规范]]。按这个格式写，主页、插件和 AI 都能读懂。

## 在微信 / 飞书里使用

接入 OpenClaw 之后，可以在聊天里说「周五前交方案」「跑步打卡」「今天有什么事」，它会按上面的格式写进这里。步骤见 [[安装说明]]。

## 删除示例内容

仓库里带 `#示例` 标签的都是演示内容。熟悉之后，点主页「欢迎」卡片里的「清除示例内容」即可一键清除：示例笔记移到 `.trash` 回收站，示例任务、闪念、收藏从清单里去掉，你自己写的内容不受影响。

「欢迎」卡片关掉后，可以在「设置 → 项目人生系统 → 欢迎栏」重新显示。
